# 🛡️ Automated GRC Compliance Auditor & Gap Analysis Tool

## 💼 Business Case & Problem Statement
In modern corporate environments, manually auditing technical infrastructure against strict compliance frameworks (like NIST or CIS) is slow, prone to human error, and costly. This project replaces outdated, manually maintained spreadsheets with an automated **Compliance-as-Code** pipeline. It bridges the gap between raw technical infrastructure and executive-level governance reporting.

## 🚀 Key Features
* **Framework Decoupling:** Uses a modular `rules.ini` registry, allowing compliance officers to update regulatory rules without changing the underlying application code.
* **Multi-Layer Scans:** Programmatically evaluates local file permissions, active configuration blocks, and environment variables.
* **Executive-Ready Reporting:** Translates raw JSON validation data into a clean, professional, color-coded PDF Gap Analysis report complete with framework IDs and specific technical remediations.
